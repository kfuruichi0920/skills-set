# 制作と検証

HTMLまたは編集可能なPowerPointを作る場合に読む。

## ツールの選択

利用環境にPresentationsスキルがある場合は、それを読み、テンプレート、制作、レンダリングの手順を併用する。本スキルは資料の論理を定め、Presentationsはファイル制作を担う。

Codexデスクトップでは`load_workspace_dependencies`で実行環境とライブラリを確認する。存在しないツールやレンダラーを使えたものとして報告しない。必要な環境が使えない場合は、完成できる範囲と不足条件を示し、途中成果を保持する。

## HTML

ユーザー指定がなければローカルで開ける単一HTMLにする。各スライドを独立した`section`とし、画面表示と印刷でページ境界を保つ。図表はSVGやHTMLで描画し、ネットワーク依存のフォントには日本語の代替フォントを設定する。

閲覧用ナビゲーションを設ける場合はキーボードでも操作できるようにし、印刷時はナビゲーションを隠す。縮小表示で文字が欠けないように、スライド全体の比率を維持する。

ブラウザーで全ページを確認する。外部フォントを使用する場合は、読み込み完了後に確認し、代替フォントでも崩れないか確認する。

## PowerPoint

環境にあるPPTX作成ライブラリを使う。本文はテキスト、図は標準図形や編集可能なグラフとして作り、ページ全体を一枚の画像にしない。写真など画像が適切な部分には画像を使う。

HTMLやSVGの座標を流用する場合は、スライド幅・高さに対する比率で変換する。pxとptを固定の比率で変換すると意図しないページ寸法になり得るため、PPTX側のサイズから換算する。

生成したPPTXをPDFまたは画像にレンダリングして全ページを確認する。日本語フォントの代替による改行も点検する。レンダラーが使えない場合はファイル構造の検査を行い、見た目の確認が未実施と明記する。

## 検証記録

制作を完了したか、内容を確認したか、全ページを視覚確認したかを区別する。数字の合計、比率の分母、期間と単位の整合を確認する。修正したページは再確認し、解消しない問題を完成扱いにしない。
