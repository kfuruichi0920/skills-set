# 情報整理と表現選択

## 1. 素材を構造化する

入力の文章、表、図、メモを意味の単位に分ける。次を、素材に存在する範囲で抽出する。

| 項目 | 読み取る内容 |
| --- | --- |
| 対象 | 人、物、組織、概念、選択肢、状態など |
| 属性 | 対象が持つ特徴、条件、分類、役割 |
| 数量と尺度 | 値、単位、分母、尺度、測定期間 |
| 時間 | 順序、開始・終了、前後、段階、変化 |
| 関係 | 階層、内訳、流れ、依存、対応、重複 |
| 伝えたい要点 | 特徴、差、傾向、問題、問い、仮説 |
| 確かさ | 事実、解釈、仮説、試算、不明 |
| 出所 | 入力内の位置、ファイル・ページ、参照資料 |

元の記述と解釈を分ける。単なる同時変化を因果としない。不明値は「不明／要確認」とし、試算を行うときは前提と式を示す。

完了条件: 主要な情報単位に出所があり、定性・定量、事実・仮説を区別できる。

## 2. 重要な軸を抽出する

まず、入力を何の観点で整理すると理解が進むかを考える。

| 軸の種類 | 問いの例 | 適した表現の例 |
| --- | --- | --- |
| 比較 | 何を、同じ何で比べるか | 比較表、共通軸の小図 |
| 分解 | 全体は何から成るか、何が寄与するか | 内訳、ツリー、滝 |
| 時間・段階 | 何がいつ変わるか、順序は何か | 時系列、工程、前後対比 |
| 関係・流れ | 誰と何がどのように結び付くか | 関係図、フロー、レーン |
| 分類・位置 | 何で分けるか、どこに位置するか | マトリクス、散布、地図 |
| 論証・条件 | どの根拠がどの主張を支えるか | 論証表、問いと答え |
| 要約・構成 | 何を先に見せると全体がつかめるか | サマリ、章構成、全体と拡大 |

各軸について、入力の根拠、見えること、比較の粒度、必要データを記録する。二軸が意味を持つときだけ二次元にする。数値がない分類軸はカテゴリとして扱い、評価点や順位を捏造しない。複数の観点が必要なら図を分ける。

完了条件: 主案の軸を選ぶ理由を説明でき、代替軸との差がわかる。

## 3. 要点とページの筋道を作る

ページごとに問いと要点を対応させる。要点は、事実、特徴、解釈、問いのいずれかとして確かさに合う書き方にする。説明資料では題名や名詞句が適切な場合もある。判断資料では、根拠を伴う判断や提言を見出しに置く。

複数枚では以下から目的に合う筋道を選ぶ。

- 順序: 時系列、手順、工程に沿う。
- 比較: 対象や前後を共通の基準で並べる。
- 分類: 一つの切り口で同じ粒度に分ける。
- 問題解決: 問題、対応、期待する変化をつなぐ。
- 因果: 根拠のある原因と結果を示す。
- 結論と根拠: 要点を証拠で支える。

見出しだけを読んで資料の目的と筋道が追えるか確認する。同じ階層の項目は粒度を揃え、共通事項はまとめる。判断が目的の場合は最後に求める決定と次の行動を置く。探索が目的なら、見えてきたこと・仮説・次に確かめることを置く。

完了条件: ページの役割が重複せず、入力にない結論を強制していない。

## 4. 表現案を比較する

候補を情報構造の違いで比較する。例えば「時間で整理する案」と「役割ごとの流れで整理する案」は異なる見え方を持つ。

各候補に、軸、型・見本ID、ラフ配置、示す要点、採用理由、失われる情報、必要な追加情報を付ける。主案は入力と目的に最も適合するものを選ぶ。型に合わない情報を削って合わせる場合は、その省略を説明する。

カタログは索引であり、全型を使う必要はない。数量の比較は棒、推移は折れ線、増減は滝、歩留まりはファネル、二量の積は面積、相関は散布、分布はヒートマップ、配分はサンキーなどからも選べる。円は構成比を読む目的に適合する場合に選び、細かな差の比較なら棒や表を検討する。

完了条件: 主案と代替案の違いが軸と配置で説明され、入力の重要情報が対応付く。

## 5. ラフ出力と検証

案出しでは主案の見出し・図表・ラベル・配置を具体化する。仕上げるより先に、情報の対応と読み取りやすさを確認する。文字や記号で表すラフでも、領域ごとの内容を示す。

共通原則:

- 軸、尺度、単位、期間を明示する。
- 比較では尺度と要素位置を揃える。
- 数量を示す長さ・面積・太さは量に比例させる。
- 線、塗り、色の意味を資料内で一貫させ、必要な凡例を置く。
- 共通事項をまとめ、差や関係が見えるようにする。
- 各要点と図表要素、元情報を対応させる。

色、フォント、余白、文字サイズ、キャンバス寸法は固定しない。指定、情報量、画面・投影・印刷などの利用条件から選ぶ。強調は読み取るべき要素に限り、装飾で関係を曖昧にしない。

数値整合、省略、根拠、軸の妥当性を確認する。完成ファイルの場合は全ページをレンダリングし、はみ出し、重なり、ラベル欠け、読みにくさを直す。未検証は未検証と表示する。

完了条件: 案が具体的に比較でき、入力から表現までの対応と制約が追える。
