# 初期配置の規則

- 入力で与えられたノード・接続・条件を落とさず、未指定の装置や方向を作らない。
- 2〜5ノードなら水平または垂直に揃える。基本サイズ160×70、ノード間80px程度の余白を出発点とし、ラベル長に合わせて広げる。
- 接続はsource/targetによるネイティブコネクタとし、ノード移動に追従させる。
- 線とラベルが図形に重ならないように配置する。複雑な配線には必要な分だけwaypointを使う。
- レイヤー・グループは意味上必要な場合だけ使う。画像化した図や独自GUIは追加しない。
- 機械検査と目視検査を区別する。Phase 1で重なり・文字切れの自動判定や最適配置を保証しない。
