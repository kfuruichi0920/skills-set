# 高速モードと精密モード

モードは検査の深さを選ぶものであり、入力の意味や必要な成果物を変えない。未指定は高速モードとし、開始時に「高速モードで進めます。精密モードへ変更できます」と伝える。指定済みなら質問を繰り返さない。

| 処理 | 高速 | 精密 |
| --- | --- | --- |
| 入力の意味・条件・例外・数値と出力の照合 | 実施 | 実施 |
| XML／形式、実図形ID、所属・接続参照の整合 | 今回のファイルだけ検査 | 同左 |
| 原図保持・注釈番号と説明対象の対応 | 実施 | 実施 |
| 図解候補の検索 | 原則Top-3。適合したら確定 | 原則Top-5。主案と代替案を比較 |
| 新規プレビューの制作 | 指定形式・埋込みに必要な分だけ | 全ページを表示できる画像を生成 |
| 線の見え方、交差、重なり、文字切れ、余白の目視検査 | 省略 | 全ページ・全コネクターを点検し、修正後に再確認 |
| 根拠資料 | 原文・時刻・出所・採用軸・主案の理由・留保・検査状況を簡潔に記す | 同内容に候補比較と表示検査の記録を加える |

高速モードでは、配置検査だけを目的とするレンダリング・拡大表示・経路の微調整を行わない。カタログ全件の展開・精読、無関係な資料の調査、スキル全体の再生成・回帰検査も行わない。検索ツールの索引読込みは許容し、エージェントは該当する参考例と今回使う図形だけを確認する。形式として必要なSVG／PNGの生成や、PlantUMLを埋め込むためのレンダリングは省かない。生成成功を目視検査済みと扱わない。

原図や入力画像の読取りは両モードで行う。省略するのは生成後の詳細な表示検査であり、説明対象を確認せずに注釈を付けることではない。

XMLが壊れている、接続先が存在しない、数量が入力と異なる、注釈が別の対象を説明するなど、意味や利用を損なう問題は高速でも修正する。制作中に明白な重なりを見つけた場合は直してよいが、全ページの詳細検査へ自動的に広げない。

精密モードの表示検査は[配置検査](drawio-layout-check.md)を使う。表示環境が利用できない場合は、精密モードを選んだことと表示未確認であることを分けて報告する。高速からの変更は今回作成したファイルへ検査を追加する。過去のoutputを再検査する依頼では、指定された対象だけを参照する。

## 個別指定と記録

「高速だが主要ページだけ確認」「精密だが線の点検は省略」のような指定も受け入れる。基準モード、追加・省略した検査、実施範囲、失敗・未確認をrationale.mdに記す。部分的な検査を全件の検査と報告しない。

実行時間の短縮幅は情報量・出力形式・環境に依存する。固定の所要時間や倍率を保証しない。スキルや版管理サンプルの改修検証はこの利用モードの対象外である。
