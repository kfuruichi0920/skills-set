参照: SRC-031（[URL一覧](../../sources/urls.md)）。関係の種類と粒度を抽出し、固有データと具体的配置をコピーせず架空の予約サービスへ適応した。

図形・表・所属・接続・ラベルをDraw.ioで編集できる。

点検記録: 政治・経済・社会・技術・環境・法律の六観点が欠けていないこと、例の確認条件と索引の目的をPNGで確認。
